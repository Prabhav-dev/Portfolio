Yggdrasil — Blind Storage System

Java-based embedded storage engine and networking middleware featuring Ascon-128 AEAD page security, B+Tree indexing, and WAL recovery with zero runtime dependencies.

Pure Java 17+ Zero Dependencies Ascon-128 AEAD B+Tree Indexing WAL Crash Recovery Raw Java NIO Swing Inspector GUI

System Architecture & Internals

Yggdrasil is an embedded storage engine built from first principles without external libraries (no Netty, no BouncyCastle, no Hibernate, no Jackson). It directly manages 4,096-byte disk pages protected with authenticated encryption.

  • Authenticated Page Security: 4 KiB pages encrypted with NIST-standardized Ascon-128 AEAD and cryptographically bound to page-specific associated data to prevent frame-swap attacks.
  • Encrypted Metadata Layer: Page 0 stores encrypted metadata and root pointers to preserve recovery and index root state safely across reboots.
  • B+Tree Indexing: Complete support for point lookups, range queries, leaf splits, and branch merges over persisted records.
  • Write-Ahead Logging (WAL): Records page after-images and tuple updates; automatically detects and discards torn trailing records during recovery.
  • Zero-Dependency NIO Server: Non-blocking Java NIO channels with manual byte buffer frame accumulation and custom binary protocol dispatch.
  • Interactive Supervisor GUI: Built-in Swing supervisor console providing live B+Tree visualization, hexadecimal raw page inspection, and security telemetry.
  • 8 TiB Address Span: Physical 4 KiB layout mapped over 32-bit signed page IDs giving a logical address span of 243 bytes.

Major Project • Architecture Concept & Prototype

Yggdrasil Memory Layer — Embedded AI Agent Memory

Embedded, token-efficient long-term persistent memory architecture for LLM agents utilizing Yggdrasil B+Tree storage and diff-based delta compression.

LLM Memory Zero-Cloud Dependency Fidelity Tiering Myers Delta Compression B+Tree Storage Model Agnostic

Addressing LLM Context Limits Without External Vector SaaS

Modern AI agents suffer from a dilemma: either forget context between turns, or burn excessive tokens and network hops piping full conversational context into external hosted vector DB services (Pinecone, Weaviate). The Yggdrasil Memory Layer solves this by embedding zero-external-dependency local storage directly alongside the application.

  • Dual Fidelity Architecture:
    • Lossy Path (Natural Language): Embeds, tags (recency, cluster), and summarizes conversational dialogue.
    • Near-Lossless Path (Code & Structured Data): Code changes are diffed using java-diff-utils-rs and stored as strict Myers deltas, preventing silent LLM hallucination of syntax or function signatures.
  • 3-Tier Compression Lifecycle:
    • Tier 1 (Raw): Recent, full-fidelity turn records.
    • Tier 2 (Summary): Aging entries compressed via diff-based delta against prior states.
    • Tier 3 (Cluster Gist): Archived memories merged into compact cluster-level semantic gists.
  • Library-First & Model Agnostic: Operates entirely offline with an optional lightweight API wrapper for local agent deployment.
